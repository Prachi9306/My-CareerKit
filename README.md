# My-CareerKit
My CareerKit is an AI-powered career counselling web app. It helps students explore, plan, and visualize their career paths through smart features like:  🤖 AI Chatbot for personalized guidance  🧭 Career Interest Quiz  🗺️ AI Career Roadmap Generator  📊 Stream-based Flowcharts (PCM, PCB, Commerce, Arts) 🏛️Government Exam Info Module
